# Mwega website

Next.js site generated from the approved preview.

- Text and data: content/site.js
- Styles: app/globals.css
- Components: components/
- Routes: app/ (one folder per page)
- Contact form email: app/api/contact/route.js (see .env.example)

Run locally with npm install, then npm run dev. Check a production build with npm run build.
